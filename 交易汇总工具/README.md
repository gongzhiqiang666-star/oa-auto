# 交易汇总工具（Windows 版）

把「交易明细 Excel」按指定汇总表结构自动汇总，一键生成结果文件。面向非技术用户设计：**下载模板 → 导入模板 → 开始计算 → 结果自动保存/下载**，全程图形界面，无需命令行。

---

## 一、功能

| 步骤 | 功能 | 说明 |
|---|---|---|
| ① | 下载模板 | 一键生成《交易汇总模板.xlsx》（含交易明细表、汇总表、使用说明三个工作表） |
| ② | 导入模板 | 选择填好交易明细的 Excel 文件（.xlsx） |
| ③ | 开始计算 | 自动汇总，进度与日志实时显示 |
| ④ | 下载结果 | 结果自动保存为「原文件名_汇总.xlsx」，可打开文件夹或另存为 |

计算规则（与原始 `trade_summary.py` 完全一致）：

- 只统计交易状态为 **“交易成功”** 的行；姓名取「所属二级」，金额取「交易金额」；
- 通道按关键字归类：联动=力pos交易、鲲鹏=鲲鹏交易、合利宝=合利宝、星驿付=星驿付；
- 普通交易按「商户费率」汇总（0.6000 → 0.6交易额）；支付类型以「特惠」开头的按支付类型汇总到特惠列；
- 每个通道的「总交易额」统计该姓名在该通道下的全部交易金额；
- 所有问题（跳过行、人员不匹配、模板缺列等）写入结果文件的「问题备注」工作表。

## 三、如何得到 Windows 可执行程序（exe）

### 方式一：GitHub Actions 自动构建（推荐，无需 Windows 机器）

1. 把本文件夹（`赵琴工作自动化`）作为一个仓库推送到 GitHub；
2. 打开仓库的 **Actions** 页面 → 左侧选 **Build Windows exe** → 点 **Run workflow**；
3. 构建完成后，在该工作流页面底部 **Artifacts** 处下载 `交易汇总工具-windows`；
4. 解压得到 `交易汇总工具.exe`，拷到任何 Windows 电脑双击即可运行，无需安装 Python。

> 每次推送 `交易汇总工具/**` 下的代码修改也会自动触发构建。

### 方式二：在 Windows 电脑上本地打包

1. 安装 Python 3.9+（安装时勾选 **Add python.exe to PATH**）；
2. 双击 `交易汇总工具/build.bat`，脚本会自动创建虚拟环境、安装依赖并打包；
3. 完成后程序位于 `交易汇总工具/dist/交易汇总工具.exe`。

> 说明：`.exe` 是单文件程序（约 15~25 MB），首次启动会稍慢（需解压到临时目录），属正常现象。
> 若杀毒软件误报，属 PyInstaller 打包程序的常见情况，添加信任即可；如需规避，可改用 onedir 模式（见 spec 注释）。

## 四、日常使用流程

1. 双击 `交易汇总工具.exe`；
2. 点 **① 下载模板**，把《交易汇总模板.xlsx》存到桌面；
3. 用 Excel 打开模板，把当月交易明细粘贴进「交易明细」工作表（第一行表头保留，红色示例行可删）；
4. 回到程序，点 **② 导入模板** 选择刚保存的文件；
5. 点 **③ 开始计算**；
6. 计算完成后结果自动保存到原文件旁边（`原文件名_汇总.xlsx`），点 **④ 打开文件夹** 或 **另存为** 即可拿到结果。

## 五、常见问题

- **提示“Sheet1 缺少必要表头”**：交易明细工作表第一行必须包含：所属二级、所属通道、商户费率、支付类型、交易金额、交易状态。
- **提示“必须包含 Sheet1 和 Sheet2”**：请使用本工具下载的模板，或在文件中新建名为 `Sheet1`、`Sheet2` 的工作表。
- **交易没算进去**：确认「交易状态」文本精确为“交易成功”；缺少姓名/通道/费率的行不会参与汇总（详见结果中的「问题备注」）。
- **结果里多出/少了人**：Sheet1 出现而模板没有的姓名会自动追加；模板有而 Sheet1 没有的姓名会计 0 并写入「问题备注」，可按需删除。
